# 🌐 Personal Portfolio Website

### Puli Sai Srinivasa Teja | Aspiring AI Full Stack Developer | Java Backend Developer

Welcome to my personal portfolio repository!

This project showcases my technical skills, professional journey, internships, certifications, projects and achievements.

Built using **HTML5, CSS3 and Vanilla JavaScript**, this portfolio is designed as a fast, responsive, accessible, and recruiter-friendly single-page website without any frontend frameworks or build tools.

## 🚀 Key Features

- **Professional Landing Page:** Recruiter-focused introduction with my name, role, headline and featured project.
- **Project Showcase:** Detailed project cards highlighting problems, solutions, functionalities, technologies and contributions.
- **Technical Skills:** Organized technical skills across programming, frontend, backend, databases and AI.
- **Professional Experience:** Internship timeline, hackathons and technical events.
- **Education & Certifications:** Academic background, certifications and extracurricular activities.
- **Resume Download:** One-click downloadable PDF resume.
- **Contact Integration:** Quick access to Email, LinkedIn and GitHub.
- **Quick Copy Actions:** Copy email address and phone number with one click.
- **Coding Profiles:** Direct links to LeetCode and HackerRank.
- **Theme Customization:** Light and dark themes with preferences remembered between visits.
- **Smooth Navigation:** Smooth scrolling, active navigation highlighting and subtle animations.
- **Responsive Design:** Optimized for mobile phones, tablets and desktop screens.
- **Accessibility:** Keyboard navigation, visible focus indicators and reduced-motion support.
- **SEO Optimization:** Meta tags, Open Graph metadata and Person structured data.

## ⚙️ Run the Project Locally

Follow these steps to run the portfolio on your local machine.

**Prerequisites:**
- Visual Studio Code
- A modern web browser
- Live Server extension (recommended)

**Steps:**

1. Clone the repository:

git clone https://github.com/Puliteja2006/my-portfolio.git

2. Open the project folder in VS Code.

3. Install the Live Server extension.

4. Right-click index.html.

5. Select **Open with Live Server**.

Alternatively, open index.html directly in your browser.

**Note:** An internet connection is required to load Google Fonts. System fonts are used as fallbacks.

## 🌍 Deployment – GitHub Pages

This portfolio can be hosted for free using GitHub Pages.

**Deployment Steps:**

1. Push the project files to the GitHub repository.
2. Open repository Settings.
3. Navigate to **Pages**.
4. Under Build and Deployment, select **Deploy from a branch**.
5. Select branch main.
6. Select folder / (root).
7. Click Save.
8. Wait for GitHub Pages to publish the website.

**Expected website URL:**

https://puliteja2006.github.io/my-portfolio/

The actual published URL and deployment status can be verified in the repository's Pages settings.

### Updating the Website

Whenever changes are made to the portfolio, use:

git add .
git commit -m "Update portfolio website"
git push

GitHub Pages will automatically publish updates after the changes are pushed.
